Bowerbird 桌面端由 **mygo/ui（Go + GPU）** 原生渲染，不再内嵌 WebView 或 React。插件不会绘制 DOM；它们返回纯 JSON，由宿主用原生视图呈现。

## 安装 SDK

<PackageManagers pkg="@bowerbird/plugin-sdk" />

SDK 主要提供 TypeScript 类型与少量纯函数，没有 React/运行时依赖，也不需要打包器。

## 创建插件目录

```text
my-plugin/
├── plugin.json
└── index.js
```

`plugin.json` 声明能力；`index.js` 只编写逻辑钩子（可选）：

```json
{
  "id": "com.example.inspector",
  "name": "Example Inspector",
  "version": "2.0.0",
  "kind": "metadata",
  "main": "index.js",
  "hooks": ["inspect"]
}
```

```js
export function inspect({ item }) {
  return {
    sections: [{ title: "Example", rows: [{ label: "Extension", value: item.extension }] }],
  };
}
```

原生预览插件则声明 `"native": "markdown"` 等宿主渲染器，可以完全省略 `main`。下一步请阅读 [开发第一个插件](/plugin-sdk/quickstart)。
