Bowerbird's desktop UI is rendered natively by **mygo/ui (Go + GPU)**. There is no embedded WebView or React runtime. Plugins return plain JSON and the host paints it with native views.

## Install the SDK

<PackageManagers pkg="@bowerbird/plugin-sdk" />

The SDK is primarily TypeScript types plus a few pure helpers. It has no React or framework runtime and needs no bundler.

## Create a plugin

```text
my-plugin/
├── plugin.json
└── index.js
```

`plugin.json` declares capabilities; `index.js` contains optional logic hooks:

```json
{
  "id": "com.example.inspector",
  "name": "Example Inspector",
  "version": "2.0.0",
  "kind": "metadata",
  "main": "index.js",
  "hooks": ["inspect"]
}
```

```js
export function inspect({ item }) {
  return {
    sections: [{ title: "Example", rows: [{ label: "Extension", value: item.extension }] }],
  };
}
```

Native preview plugins declare a host renderer such as `"native": "markdown"` and may omit `main` entirely. Continue with [Build your first plugin](/en/plugin-sdk/quickstart).
