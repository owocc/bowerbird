## Why Build Bowerbird Plugins?

- **Sandboxed ES Modules**: Packaged as clean modern ES Modules; the host injects secure host APIs and theme contexts at runtime.
- **Multi-Viewport Presentation**: Supports both full-window interactive Viewports and compact right Inspector extensions.
- **Format Preemption Matching**: Fine-grained priority numbers (1~85) match file extensions, enabling seamless community extensions.
- **1-Click System Protocol**: `bowerbird://plugin/install` protocol allows users to install plugins directly from browsers or terminal scripts.
