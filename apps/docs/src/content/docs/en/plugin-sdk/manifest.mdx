Every plugin contains a `plugin.json`. The native host uses it for registration, extension matching, permissions and priority.

## Example

```json
{
  "id": "official.markdown-preview",
  "name": "Markdown Preview",
  "version": "2.0.0",
  "description": "Native GitHub-flavored Markdown preview",
  "author": "Bowerbird Team",
  "kind": "preview",
  "native": "markdown",
  "priority": 50,
  "extensions": ["md", "markdown"],
  "mimePrefixes": ["text/markdown"],
  "license": "MIT"
}
```

## Fields

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | `string` | yes | Unique namespaced id (e.g. `com.example.my-plugin`) |
| `name` | `string` | yes | Display name |
| `version` | `string` | yes | SemVer version |
| `kind` | `preview` \| `metadata` \| `resolver` \| `action` | no | Capability group; defaults to `preview` when `native` is set |
| `native` | `string` | no | Host renderer id such as `markdown`, `audio`, `psd`, `prompt` |
| `main` | `string` | no | Logic hook entry; native plugins may omit it |
| `extensions` | `string[]` | no | Lowercase extensions without a dot |
| `mimePrefixes` | `string[]` | no | MIME prefixes or complete types |
| `urlHosts` | `string[]` | no | Resolver host index, supports `*.example.com` |
| `urlPatterns` | `string[]` | no | Regex list matched after the host index hits |
| `priority` | `number` | no | Match priority; higher wins |
| `supportsZoom` | `boolean` | no | Route zoom controls to the native preview |
| `permissions.network` | `string[]` | no | `fetch` host allow-list, supports `*.example.com` |
| `permissions.process` | `string[]` | no | Executables allowed for `host.spawn` |
| `permissions.openExternal` | `boolean` | no | Allow `host.platformOpen` for external links; defaults to `false` |
| `settings` | `object[]` | no | Settings fields (`key`, `label`, `help`, `placeholder`, `default`, `secret`) |
| `hooks` | `string[]` | no | Implemented hooks: `resolveUrl`, `inspect`, `actions`, `runAction`, `thumbnail` |

The structured preview form is also supported:

```json
{
  "kind": "preview",
  "preview": {
    "renderer": "audio",
    "extensions": ["mp3", "flac"],
    "mimePrefixes": ["audio/"],
    "supportsZoom": false,
    "priority": 60
  }
}
```

<Aside type="caution" title="Priority and fallback">
  When several enabled plugins match a format, the highest `priority` wins. Disabled or failing plugins fall back to the native default view.
</Aside>
