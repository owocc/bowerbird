Plugins come in two shapes: **native preview declarations** and **logic hooks**. Neither needs React, CSS or a build step.

## 1. Native preview plugin

Ask the host to render Markdown with `mygo/ui`:

```json
{
  "id": "com.example.markdown",
  "name": "Example Markdown",
  "version": "2.0.0",
  "kind": "preview",
  "native": "markdown",
  "extensions": ["md", "markdown"],
  "mimePrefixes": ["text/markdown"],
  "priority": 50
}
```

`native` is a host renderer (`image`, `video`, `markdown`, `audio`, `psd`, `prompt`). With no `main`, the plugin is entirely executed by Go and does not need Node.

## 2. Logic hook plugin

`index.js` is a plain ES module exporting `inspect`, `resolveUrl`, `actions`, and friends:

```js
/** @typedef {import("@bowerbird/plugin-sdk").InspectResult} InspectResult */

/** @returns {InspectResult|null} */
export function inspect({ item }) {
  if (!item.prompt) return null;
  const words = item.prompt.trim().split(/\s+/).length;
  return {
    sections: [{
      title: "AI Prompt",
      rows: [
        { label: "Words", value: String(words) },
        { label: "Characters", value: String(item.prompt.length) },
      ],
      textBlocks: [{ title: "Prompt", text: item.prompt }],
    }],
  };
}
```

## 3. Validate the manifest

```ts
import { validatePluginManifest } from "@bowerbird/plugin-sdk";

const result = validatePluginManifest(JSON.parse(raw));
if (!result.valid) console.error(result.errors);
```

<Steps>
  <Step title="Return plain data">Hooks receive and return JSON. Never touch the DOM or browser-only APIs.</Step>
  <Step title="Declare permissions">Network hosts go in `permissions.network`, external executables in `permissions.process`. Everything is denied by default.</Step>
  <Step title="Let the host render">Use a `native` renderer or declarative `inspect` sections instead of shipping UI.</Step>
</Steps>
