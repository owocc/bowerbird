Plugins run in an embedded moejs runtime inside the Go process. The host injects only `globalThis.host`: no DOM, filesystem, or unrestricted network.

## `host.fetch(url, init?)`

Requests are limited by the `permissions.network` allow-list:

```js
const res = await host.fetch("https://api.example.com/items", {
  headers: { Accept: "application/json" },
});
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();
```

Missing permissions or hosts outside the allow-list throw immediately.

## `host.settings.get(key)`

Read values saved in the plugin settings card:

```js
const endpoint = host.settings.get("endpoint") || "https://api.example.com";
```

```json
{
  "permissions": { "network": ["api.example.com"] },
  "settings": [
    { "key": "endpoint", "label": "API endpoint", "placeholder": "https://…" }
  ]
}
```

## `host.log(level, message, detail?)`

Write plugin diagnostics to Bowerbird's unified log window. The host adds the
plugin id and current hook automatically:

```js
host.log("info", "resolved pin", url);
host.log("warn", "no candidates", "falling back to direct import");
```

`console.log/info/warn/error/debug` are forwarded to the same stream. Every
hook start/end, result, error, and `fetch`, `settings.get`, `spawn` call is
recorded automatically.

## `host.spawn(command, args?)`

Run an executable declared in `permissions.process` after the user grants it in Settings. Returns stdout:

```js
const info = host.spawn("magick", ["identify", "-format", "%wx%h", item.filePath]);
```

## Hook return shapes

- `inspect({ item })` → `{ sections: [{ title, rows, textBlocks }] }`
- `resolveUrl({ url })` → `{ url, candidates, sourceUrl, name, tags }`
- `actions(ctx)` → `[{ id, title, icon }]`
- `runAction({ id, ...ctx })` → any JSON
- `thumbnail({ filePath, mimeType })` → `{ imagePath, width, height }`

The host renders these with shared `mygo/ui` components. Plugins cannot return HTML, CSS or React components.
