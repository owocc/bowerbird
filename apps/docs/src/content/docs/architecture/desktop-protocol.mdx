Bowerbird 桌面端内置了轻量级本地控制服务，使得网页端市场可以探测客户端在线状态，并实现无缝的一键同步安装。

## 通信架构

```text
+-----------------------+                    +------------------------+
|  Bowerbird 网页市场   |                    |   Bowerbird 桌面应用   |
|   (Marketplace Web)   |                    |    (Desktop Client)    |
+-----------+-----------+                    +-----------+------------+
            |                                            |
            | 1. HTTP 探测 (localhost:47990/ping)         |
            +------------------------------------------->|
            |    HTTP 200 { connected: true }            |
            |<-------------------------------------------+
            |                                            |
            | 2. API 安装 (POST /api/plugins/install)     |
            +------------------------------------------->|
            |    HTTP 200 { success: true }              |
            |<-------------------------------------------+
            |                                            |
            | 3. (离线降级) bowerbird:// OS 协议唤起      |
            +===========================================>|
```

## 安全模型

- **局域网回环隔离**: 服务仅绑定于 `127.0.0.1`，严格拒绝外部网络发起的非法访问。
- **CORS 保护**: 仅允许受信任的官方域名或通过用户授权的来源进行跨源操作。
- **一键安装确认**: 任何新插件在首次加载与代码执行前，客户端均会提示用户检查插件权限与来源。
