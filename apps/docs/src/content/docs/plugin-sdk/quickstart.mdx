插件只有两种形态：**原生预览声明**与**逻辑钩子**。两者都不需要 React、CSS 或打包步骤。

## 1. 原生预览插件

让宿主用 `mygo/ui` 绘制 Markdown：

```json
{
  "id": "com.example.markdown",
  "name": "Example Markdown",
  "version": "2.0.0",
  "kind": "preview",
  "native": "markdown",
  "extensions": ["md", "markdown"],
  "mimePrefixes": ["text/markdown"],
  "priority": 50
}
```

`native` 取值为宿主支持的渲染器（`image`、`video`、`markdown`、`audio`、`psd`、`prompt`）。没有 `main` 时插件完全由 Go 执行，不需要 Node。

## 2. 逻辑钩子插件

`index.js` 是普通 ES 模块，导出 `inspect`、`resolveUrl`、`actions` 等函数：

```js
/** @typedef {import("@bowerbird/plugin-sdk").InspectResult} InspectResult */

/** @returns {InspectResult|null} */
export function inspect({ item }) {
  if (!item.prompt) return null;
  const words = item.prompt.trim().split(/\s+/).length;
  return {
    sections: [{
      title: "AI Prompt",
      rows: [
        { label: "Words", value: String(words) },
        { label: "Characters", value: String(item.prompt.length) },
      ],
      textBlocks: [{ title: "Prompt", text: item.prompt }],
    }],
  };
}
```

## 3. 验证清单

```ts
import { validatePluginManifest } from "@bowerbird/plugin-sdk";

const result = validatePluginManifest(JSON.parse(raw));
if (!result.valid) console.error(result.errors);
```

<Steps>
  <Step title="返回纯数据">钩子接收 JSON、返回 JSON，禁止操作 DOM 或依赖浏览器 API。</Step>
  <Step title="声明权限">网络访问写入 `permissions.network`，外部程序写入 `permissions.process`，默认全部拒绝。</Step>
  <Step title="交给宿主渲染">需要界面时使用 `native` 渲染器或 `inspect` 声明式区块，而不是自带 UI。</Step>
</Steps>
