原生插件是免构建的目录，直接打包 `plugin.json`、可选的 `index.js` 与本地化资源即可。

## 目录与 ZIP

```text
my-plugin/
├── plugin.json
├── index.js
└── locales/zh-CN.json
```

```bash
zip -r my-plugin-v2.0.0.zip my-plugin
```

ZIP 根目录可以直接是插件目录，也可以包一层同名文件夹；安装器会自动展平。

## 安装

- 设置 → 插件 → **安装插件…**，输入 `plugin.json` 或 ZIP 的 HTTP(S)/`file://` 地址。
- 或把插件目录放入 `<UserDataDir>/plugins/`，宿主扫描后即可启用。
- 官方插件在打包版本中作为内置插件注册；本地同名目录会覆盖内置副本，便于开发。

## 更新与状态

`<UserDataDir>/plugins/native-plugins.json` 保存插件的启停与设置值。卸载远程插件会删除其目录，内置插件不可卸载但可以禁用。

<Aside type="tip" title="无需 Vite/Rollup">
  如果你的插件只声明 `native` 预览或编写普通 ES 模块钩子，就不需要任何构建产物；直接把源码作为发布包即可。
</Aside>
