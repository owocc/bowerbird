## 为什么选择 Bowerbird 插件架构？

- **极致纯净沙箱**: 插件采用现代 ES Module 打包，宿主通过隔离环境注入安全的宿主 API 与主题上下文。
- **双端多视口呈现**: 同时支持在主视口（Viewport）进行全屏快速预览，以及在右侧属性检视器（Inspector）提供辅助元数据透视。
- **格式优先抢占式匹配**: 通过优先权数字（Priority 1~85）与文件扩展名匹配，支持社区插件无缝增强核心预览。
- **跨平台一键唤起**: 支持通过 `bowerbird://plugin/install` 协议在浏览器或终端中直接触发桌面端安全安装。
