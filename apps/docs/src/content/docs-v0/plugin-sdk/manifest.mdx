每个 Bowerbird 插件根目录下必须包含一个标准 `manifest.json` 文件。宿主应用根据清单进行静态注册、扩展名关联与优先级排序。

## 示例清单文件

```json
{
  "id": "official.markdown-preview",
  "name": "Markdown Preview",
  "version": "1.0.0",
  "description": "Rich Markdown preview with syntax highlighting and outline navigation",
  "author": "Bowerbird Team",
  "kind": "preview",
  "priority": 50,
  "extensions": ["md", "markdown", "mdown", "mkd", "mdwn"],
  "mimePrefixes": ["text/markdown", "text/x-markdown"],
  "supportsZoom": false,
  "main": "index.js",
  "license": "MIT"
}
```

## 字段规范参考

| 字段名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 是 | 唯一反向域名命名空间标识符（如 `com.example.my-plugin`） |
| `name` | `string` | 是 | 插件显示名称 |
| `version` | `string` | 是 | 语义化版本号（遵循 SemVer 规范，如 `1.0.0`） |
| `description` | `string` | 是 | 简要功能说明 |
| `author` | `string` | 是 | 开发者或组织机构名称 |
| `kind` | `"preview"` \| `"metadata"` | 是 | 插件类型：`preview` 为主视口预览，`metadata` 为右侧属性检视器扩展 |
| `priority` | `number` | 是 | 评估优先级（数值越大越优先评估，核心插件一般为 50~85） |
| `extensions` | `string[]` | 是 | 支持的小写文件扩展名数组（不包含前导点，如 `["md", "markdown"]`） |
| `mimePrefixes` | `string[]` | 否 | 支持的 MIME 类型前缀（如 `["audio/", "image/"]`） |
| `supportsZoom` | `boolean` | 否 | 是否在主顶部工具栏呈现标准缩放控件（默认 `false`） |
| `main` | `string` | 否 | 入口脚本产物相对路径（默认 `"index.js"`） |
| `license` | `string` | 否 | 开源软件许可证（如 `"MIT"`, `"Apache-2.0"`） |

<Aside type="caution" title="优先级评估规则">
  当某格式被多个插件声明时，宿主将优先匹配 `priority` 最高且启用的插件。若最高优先级插件抛出异常，宿主将平滑降级调用下一优先级或原生基础组件。
</Aside>
